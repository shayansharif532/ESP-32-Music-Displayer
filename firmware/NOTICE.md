# Provenance of the firmware

The firmware started from Waveshare's official ESP-IDF example **`02_lvgl_demo_v9`** for this exact board
(<https://github.com/waveshareteam/ESP32-S3-Touch-LCD-4B>, `examples/esp-idf/02_lvgl_demo_v9`, repository commit
`62c38908a15f1ce45f18b76caed7436cd9cbc22a`; that repository is Apache-2.0 per its `LICENSE.txt`: "Unless a file states
otherwise, this repository is licensed under the Apache License 2.0"). It uses Waveshare's board-support component
`waveshare/esp32_s3_touch_lcd_4b` 2.0.0 (Apache-2.0, `LICENSE` inside the package) and LVGL 9.5.0 (MIT), both fetched by
the ESP-IDF component manager at build time (not vendored; exact versions are pinned in `dependencies.lock`).

The pristine Waveshare example is preserved in the git history (commit `d64ad06`, "Milestone 1"); compare against it to see
exactly what is left of it. What remains today:

| File | State relative to the Waveshare example |
|---|---|
| `main/idf_component.yml` | **byte-identical** (dependency declaration of the example) |
| `CMakeLists.txt` | a few boilerplate lines of the example remain; the rest was written for this project |
| `partitions.csv` | derived from the example's table; changed (an `idle_img` data partition was carved out of the unused `storage` partition, see below) |
| `sdkconfig.defaults` | section A ("hardware baseline") is Waveshare's verified flash / PSRAM / CPU settings; section B and everything below is this project's |
| `main/main.c`, `main/CMakeLists.txt` | **rewritten**; only the include list and the `app_main` skeleton resemble the example |
| everything else under `main/` and `components/` | written for this project |

Files that came from the Waveshare example keep their Apache-2.0 licence; the modifications made to them are stated here
(Apache-2.0 section 4(b)). Waveshare's wiki pages, schematic, demo archive and factory firmware are **not** part of this
repository and must not be added (see `.gitignore`).

## Added later (not part of the Waveshare example)

- `partitions.csv`: a 1 MB `idle_img` data partition (the idle screen's background picture, raw access) was carved out of the unused
  7 MB `storage` partition, which is now 6 MB. The application (`factory`) and `nvs` offsets are unchanged.
- `components/idle_screen/font_clock.c` is generated by `tools/gen_clock_font.py`: the digits `0-9` and `:` of **Montserrat Medium**
  (Copyright 2011 The Montserrat Project Authors, SIL Open Font License 1.1, <https://openfontlicense.org>) rasterised at 128 px.
  It is a derived font and **stays under the OFL 1.1** (not under this project's licence); the licence text is in
  `../LICENSES/OFL-1.1-Montserrat.txt`. The TTF is the one LVGL ships in its own repository for generating its built-in fonts
  (`scripts/built_in_font/Montserrat-Medium.ttf`); it is not copied into this repository.
